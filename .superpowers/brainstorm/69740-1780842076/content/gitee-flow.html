数据流架构

⚙ 前后端交互
🌐 Gitee API ← HTTP → 🐍 FastAPI 后端 ← REST → 🖥 Vue 前端
/api/gitee/repos?owner=xxx → 获取仓库列表（Gitee API）
/api/gitee/repos/{repo}/stats → 获取基础统计（Gitee API）
/api/gitee/clone → Clone 到本地 + 跑 git log
/api/gitee/analyze/{repo} → 深度分析（复用现有 git log 解析）
